Solid Dashboard is a hands-on learning lab for Solid.js, exploring reactivity primitives, fine-grained DOM updates, state management, and advanced patterns — built with Solid.js 1.9, Kobalte UI, Tailwind CSS v4, and Vite.

## Functional Perspective

### Purpose

An interactive dashboard and workshop that serves as a deep-dive into Solid.js fundamentals and advanced patterns, demonstrating how fine-grained reactivity works without a virtual DOM.

### Key Features

<Feature icon="zap" title="Reactivity Primitives">
  Explores createSignal, createEffect, createMemo, createStore, and createResource — each demonstrated in interactive workshop sections with live counters and effect trackers.
</Feature>

<Feature icon="toggle-right" title="Reactivity Modifiers">
  Demonstrates batch(), untrack(), and produce() to show how grouped signal writes, untracked reads, and Immer-style mutations work under the hood.
</Feature>

<Feature icon="git-branch" title="Control Flow Components">
  Uses Solid's compiled control flow — Show, For, Switch/Match, Suspense, and ErrorBoundary — that map directly to DOM operations without diffing.
</Feature>

<Feature icon="database" title="State Management with Context">
  Full settings store pattern using createStore with deep reactive Proxy, path-based setters, a Context provider/consumer split, and centralized action factories.
</Feature>

## Technical Perspective

### Tech Stack

<Feature icon="code-2" title="Framework">
  Solid.js 1.9 with TypeScript — compile-time JSX transformation that produces fine-grained DOM effects with no virtual DOM reconciliation.
</Feature>

<Feature icon="layout" title="UI Components">
  Kobalte for accessible, unstyled compound components (Tooltip, Progress, Badge, Button, ToggleButton, Collapsible) composed from semantic parts.
</Feature>

<Feature icon="paintbrush" title="Styling">
  Tailwind CSS v4 with class-based dark mode toggled reactively by the Solid store, using the single-import syntax and @apply composition.
</Feature>

<Feature icon="rocket" title="Build & Deploy">
  Vite for fast HMR and optimized production builds with lazy() code splitting. Deployed to Vercel.
</Feature>

### Architecture

<Feature icon="layers" title="Project Structure">
  Clean separation into pages (Dashboard, Settings, Workshop), shared components (Layout, Header, Sidebar, DataTable), and a dedicated stores layer for global state.
</Feature>

<Feature icon="table" title="Snapshot Pattern">
  DataTable implements the snapshot pattern — createResource feeds a createEffect that writes to a snapshot signal, ensuring the UI always shows last-good data during page transitions instead of flashing empty.
</Feature>
